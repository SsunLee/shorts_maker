# UI Regression Prevention

이 문서는 Shorts Maker UI 작업 시 컨트롤 겹침, 잘림, 반응형 깨짐을 줄이기 위한 기준입니다.

## 원칙

- 새 컨트롤을 기존 줄에 단순 추가하지 않는다.
- 기능군 단위로 그룹을 나눈다. 예: 맞춤, 자르기, 파일, AI, 일괄 적용.
- 긴 텍스트 버튼은 좁은 폭에서 줄바꿈되거나 아이콘 중심으로 축약될 수 있게 한다.
- 툴바 내부 컨트롤에는 `min-w-0`, `max-w-full`, `flex-wrap`, `grid` 기준을 명확히 둔다.
- 슬라이더 + 숫자 입력처럼 폭이 큰 컨트롤은 별도 row 또는 compact panel로 분리한다.
- 화면 미리보기와 실제 렌더/다운로드/업로드 결과가 달라지지 않도록 저장값과 렌더러를 같이 수정한다.

## 금지 패턴

- 한 `flex flex-wrap` 줄에 모든 버튼, select, slider, input을 몰아넣기.
- `min-w-[260px] flex-1` 같은 큰 컨트롤 옆에 체크박스/버튼을 같은 row로 배치하기.
- 특정 기능을 화면 미리보기에만 반영하고 서버/브라우저 렌더러에는 반영하지 않기.
- 라이트/다크 모드 중 하나만 보고 툴바 색상을 고정하기.
- 모바일이나 700~900px 폭 확인 없이 배포하기.

## 권장 구조

- 1행: 핵심 선택값
  - 이미지 맞춤, 박스 채우기, AI 생성 사용
- 2행: 자르기/세부 조정
  - X 슬라이더, X 숫자, Y 슬라이더, Y 숫자, 중앙 초기화
- 3행: 파일/일괄 작업
  - 가져오기, 다운로드, 제거, 화면 꽉 채우기, 적용 대상, 동일 적용
- 4행 이후: AI 프롬프트처럼 긴 입력 폼

## 반응형 기준

- 360px: 모바일 탭바와 겹치지 않아야 한다.
- 430px: 주요 버튼이 화면 밖으로 사라지지 않아야 한다.
- 768px: 툴바가 가로로 넘칠 경우 내부 스크롤 또는 줄바꿈이 동작해야 한다.
- 1024px: 사이드 패널과 툴바가 겹치지 않아야 한다.
- 1280px 이상: 불필요하게 넓게 퍼지지 않고 기능군이 읽혀야 한다.

## 배포 전 체크리스트

- 인스타그램 > 템플릿에서 텍스트/이미지/비디오/도형 레이어를 각각 선택한다.
- 라이트 모드와 다크 모드에서 툴바 텍스트가 읽히는지 확인한다.
- 430px, 768px, 1024px, 1280px 폭에서 툴바 겹침이 없는지 확인한다.
- 이미지/비디오 맞춤값이 화면 미리보기와 PNG/MP4 렌더 결과에 동일하게 반영되는지 확인한다.
- 새 버튼이나 select가 다른 기능군 위로 떠오르거나 가려지지 않는지 확인한다.
